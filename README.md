# Truth Teller Pro

give me front end to the prompt i given Create a simple and modern Fake News Detection System for my final-year CSE project.

The system should allow users to enter a news headline or news article and click “Check News”.

The application should use Machine Learning and NLP to predict whether the news is REAL or FAKE.

Features:

Home page

User login and registration

News input page

REAL/FAKE prediction

Confidence percentage

Prediction result page

Analysis history

Admin dashboard

Simple charts showing REAL vs FAKE news

Responsive and attractive UI

Technologies:

Frontend: React, HTML, CSS, JavaScript

Backend: Python Flask

Machine Learning: Python, Scikit-learn, NLP, TF-IDF

Database: MySQL

Create a clean, professional UI suitable for a final-year CSE project.

Also include sample data and make the project easy to understand and demonstrate during a viva.
